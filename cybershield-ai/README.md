# CyberShield AI — Spam & Scam Detector

An educational Community Engagement Project about social media awareness in a school. The app uses a real TF-IDF and Multinomial Naive Bayes model trained on the public UCI SMS Spam Collection. It is a learning aid, not a security product: predictions can be wrong, and **HAM does not mean safe**.

## Install on Windows

Open PowerShell in the `cybershield-ai` directory. Python 3.9 or later is recommended.

```powershell
py -3 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install -r requirements.txt
```

If PowerShell blocks activation, either use `Set-ExecutionPolicy -Scope CurrentUser RemoteSigned` if permitted on your computer, or call the environment's Python directly: `\.venv\Scripts\python.exe -m pip install -r requirements.txt`.

## Dataset and model training

The source is the [UCI SMS Spam Collection](https://archive.ics.uci.edu/dataset/228/sms+spam+collection); see [dataset/README.md](dataset/README.md) for source and manual setup. With an internet connection, training downloads the UCI archive automatically if the extracted file is absent. To prepare it manually, download the archive from UCI and put its `SMSSpamCollection` file in `dataset/`.

Train before starting the detector:

```powershell
python train_model.py
```

The script cleans invalid rows, makes a stratified 80/20 train/test split with random seed 42, fits TF-IDF on the training messages, and trains Multinomial Naive Bayes. Inference uses the trained model's spam probability with a 0.15 cutoff (rather than the default 0.50) to favor catching more spam. The script prints accuracy, spam precision, spam recall, spam F1, and a confusion matrix at that same cutoff for the held-out split. This tradeoff can create more false alarms; results depend on the split and dataset. The saved `models/spam_classifier.joblib` and `models/tfidf_vectorizer.joblib` files are created locally and should be regenerated after changing the dataset or training code.

To use an already-extracted dataset at another location:

```powershell
python train_model.py --dataset "C:\path\to\SMSSpamCollection"
```

## Run the website

```powershell
python app.py
```

Open http://127.0.0.1:5000. The Flask server binds to the local computer only and runs without debug mode. Train the model first; without both saved artifacts the pages still open, but the prediction endpoint returns a clear setup error instead of inventing an answer.

## Try the features

- **Home:** follow the detector, safety-guide, and quiz links; all five navigation pages are available from the header.
- **Message Detector:** choose one of the four examples or enter fictional text, press Predict, review the model label and safety tips, then try Clear. Empty input is rejected; the counter shows the 5,000-character limit; Ctrl+Enter (Cmd+Enter on Mac) also submits.
- **Awareness Quiz:** answer all ten questions, read the immediate explanation, view the score and tailored recommendation, then restart.
- **Cyber Safety:** review all eleven plain-language topics and their warning signs, examples, and protections.
- **Good Habits:** review practical habits for privacy, passwords, links, respectful sharing, and asking for help.

Example messages (these are test inputs, not promised results):

- Likely ordinary: `Hi, are we still meeting at the library after class? I'll be there at 3.`
- Likely suspicious: `URGENT! You have won a £1,000 gift voucher. Claim now by calling 0906 123 4567.`
- Personal-safety practice: `We just met online. Don't tell anyone we are chatting. Send me your live location so I can surprise you.`

These are test inputs, not promised results. The SMS spam model is not a harassment, grooming, threat, or personal-safety detector; a concerning message can receive a HAM label. Dataset coverage is limited, so discuss mistakes as part of the demonstration and always prioritize real-world safety guidance over the model output.

## How the parts communicate

The browser's detector JavaScript sends the entered text as JSON to Flask at `POST /predict`. Flask validates size and content, transforms the message with the saved TF-IDF vectorizer, and asks the saved classifier for `spam` or `ham`. It returns the label and category-specific educational guidance as JSON; JavaScript updates the page without reloading. Quiz questions and scoring run locally in JavaScript and are not sent to the server. Submitted message text is not written to a database, file, or application log.

## Test the JSON endpoint

With the server running and model trained, PowerShell can send a fictional sample:

```powershell
$body = @{ message = 'URGENT! Claim your prize now by calling 0906 123 4567.' } | ConvertTo-Json
Invoke-RestMethod -Uri http://127.0.0.1:5000/predict -Method Post -ContentType 'application/json' -Body $body
```

An empty message should return HTTP 400, text longer than 5,000 characters should return HTTP 400, and a request over the server body limit returns HTTP 413. If artifacts are missing, `/predict` returns HTTP 503. The response never includes internal exception details.

## Common issues

- **`py` or `python` is not found:** install Python 3 from python.org, enable the launcher/PATH option, restart the terminal, and check `py --version`.
- **Dependency installation fails:** activate `.venv`, confirm internet access, then rerun `python -m pip install -r requirements.txt`. On a managed school device, ask its administrator about package installation.
- **Dataset download fails:** check internet access and the UCI dataset page; download and extract `SMSSpamCollection` manually into `dataset/`, then rerun training.
- **Detector says the model is not trained:** run `python train_model.py` in this directory and confirm both `.joblib` files exist in `models/` before restarting Flask.
- **Port 5000 is already in use:** stop the other local server or change the port in the final `app.run` line of `app.py` and open the matching local address.
- **A message gets an unexpected result:** this is a real model with limited training examples, not a rule-based security scanner. Verify the sender independently and ask a trusted adult.

## Privacy and responsible use

There is no database and no message logging. The browser sends the text to this locally running Flask app only to make the requested prediction. Do not submit real private messages, passwords, OTPs, bank details, or personal information. Do not open suspicious links or scan unknown QR codes. Ask a trusted adult before acting on a concerning message. A HAM result is not proof that a message is safe.
